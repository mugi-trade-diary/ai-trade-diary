# AIトレード日記：承認前の収益化キット

調査日：2026-10-30（日本時間）。実売上・純利益・顧客数は UNKNOWN。
これは下書き制作と手入力証憑の集計ツールです。投稿、決済、メール送信、契約、デプロイ機能はありません。
`config.json` の許可を true にすると下書き生成も停止します。承認後の本番接続は別の実装・レビューが必要です。

## 使い方（Python 3.11以上、追加パッケージなし）

リポジトリのルートで実行します。

```powershell
python -m unittest discover -s revenue -p 'test_*.py' -v
python revenue/engine.py build --start 2026-11-01 --output revenue/generated/review-20261101
python revenue/engine.py report revenue/ledger.blank.json
```

`generated/review-20261101/index.html` をローカルで開いて導線を確認します。無料シートの保存だけ利用可能。日付は仮日程で、投稿予約ではありません。同じ出力先は上書きしません。
`calendar.json` は30本の編集用骨子です。共通の構成を使うため、各回の固有例・演出・実際の読み上げ時間の編集を経るまで公開用動画とは呼びません。

収支入力は `ledger.blank.json` を `revenue/private/` にコピーして使います。証憑や購入者情報をGitHubへ追加しないでください。金額は円の整数、同一月・同一会計基準で入力。`null` は未確認、0は確認済みゼロです。`reconciled=true` は人が決済明細、返金、請求書、税額を照合したときだけ設定します。ツール自体は外部証憑に接続しません。

## 毎日の制作運用

1. 週1回、7本分のテーマと架空例を編集。ムギ＝体験の語り手、メル＝記録整理、クウ＝振り返りの問い、ハム＝こころのケア・歌。歌は権利確認後のみ。
2. 既存画像の表情・位置・切り替えを使い、縦1080×1920の編集プロジェクトへ配置。字幕は画面下の操作領域を避ける。1本1テーマ、冒頭3秒で状況、最後に無料シートを案内。
3. まずはShotcutの無料編集＋自分の録音または無音字幕。FFmpegで一括出力する拡張も可能。既存音楽は権利が不明なら使わない。
4. 各回に異なる架空の記入例と会話を入れる。単純な画像・字幕ループを再生報酬対象と見込まない。
5. 台本→映像→権利・AI表示・自社宣伝表示→ユーザー承認→手動投稿。投稿完了のURL・時刻・content_idを非公開台帳へ保存。
6. 翌日と7日後にTikTok Studioで再生、視聴時間、完視聴、プロフィール訪問を記録。販売への貢献を週次比較。

毎日投稿は公開承認後の運用目標で、今回は予約・スケジュールを作成しません。制作時間の上限案は週2時間のまとめ作業＋毎日10分。超過時は短縮し、量を優先して品質や規約確認を省略しません。

## コストと停止基準

現在の承認済み追加支出：0円。API呼出し・Runway生成・有料契約は行わない。
提案する初月現金予算：税込・為替手数料・失敗生成・ホスティング・ツールを含め3,000円/月、変動費100円/日。広告0円、年間契約0円、追加入金0円。承認前はこの提案枠も使えません。
固定契約は日額上限とは別に全額を月間予算へ予約し、残額不足なら契約不可。決済手数料・返金は売上から別控除し、予算に隠しません。

Runway API公式：1 credit=$0.01、Turbo=5 credits/秒、Gen-4.5=12 credits/秒。以下は映像のみ、30日、再生成なしの計算です。[R1]

| 毎日の新規生成量 | Turbo credits/月 | API USD/月 | 2回生成した場合 |
|---|---:|---:|---:|
| 0秒（既存素材編集） | 0 | 0 | 0 |
| 5秒 | 750 | 7.50 | $15 |
| 10秒 | 1,500 | 15 | $30 |
| 30秒（複数クリップ） | 4,500 | 45 | $90 |
| 60秒（複数クリップ） | 9,000 | 90 | $180 |

Gen-4.5は5秒/日で1,800 credits=$18/月、60秒/日で21,600 credits=$216/月。画像・音声・音楽は別料金。円換算は実際の決済レート・税で行い、固定の換算値を実費としません。
WebプランはStandard月払い$15・年払い月換算$12/625 credits、Pro $35・$28/2,250、Max $95・$76/9,500、無料125は一回限り。[R2]
APIとWebの残高・契約は混同しません。Web価格表にTurboの625 credits=104秒、2,250=375秒という換算があり、ヘルプの5 credits/秒と一致しません。[R2,R3] 見積りはAPI公式単価を明示して使用。実際のWeb生成前に画面の消費量を確認し、高い方で予算を確保します。
追加予算の80%で新規有料制作停止・見直し、100%で停止。無料編集にもPC電気代・作業時間はあるため「利益率100%」とは表示しません。

## KPIと利益計測

- `content_id` は1動画1ID。UTMは source=tiktok、medium=organic_social、campaign=diary_pilot、content=ID。個人情報をURLに入れない。
- プロフィールの共通リンクだけでは動画ごとの正確な帰属はできません。共通リンクはcampaign単位、投稿別コードは補助、自己申告は自己申告として保持。推定売上を実測に混ぜない。
- 同じ週・同じ集計条件で「再生→プロフィール訪問→LPセッション→無料DL→支払成功」を観測。LP/DLは同意方針・プライバシー表示を整えてから導入する集計基盤が必要で、今回のHTMLは送信しません。
- ダウンロードクリックと保存成功・利用開始を区別。購入は決済側の重複排除済み注文数。ファネル各段階は必ずしも同一ユーザーではなく、率は参考値です。
- 実売上＝決済成功総額−返金−チャージバック。純利益＝実売上−決済費−制作費−広告−ホスト−その他費用−税。労働換算後利益は別表示。税額未確定なら純利益はUNKNOWN。
- 入金額と売上は違います。決済残高・入金待ち・振込額を別照合し、既に控除した手数料を二重控除しない。月次一括入力は決済一覧を集計済みの値だけを使用。
- 継続課金開始後はMRR（返金・単発を除く）、月初有料会員数、解約数、翌月継続率、1人当たりサポート時間を別管理。

仮定例：980円×10件=9,800円、カード手数料約353円、制作等3,000円なら税・返金・労働控除前6,447円。実績ではありません。返金・税なしという仮定で固定費3,000円の損益分岐は4件ですが、労働や追加費用で増えます。
週次判断の仮ルール：100 LPセッションでDLが10未満なら無料提供と導線を改善。DL30件で購入0なら商品価値・価格を聞き直し、広告や生成費を増やさない。母数未達は判断保留。2週連続で労働換算後赤字なら有料制作を停止。これらは業界平均ではなく初期実験の停止基準です。

## 権利・規約・投資助言リスク

素材台帳にファイル名、作者/生成元、取得日、規約URLと版、商用利用/改変/配信範囲、声・肖像の同意、確認者を記録。既存リポジトリにあることは権利の証明ではありません。AI生成でも第三者の権利侵害が許されるわけではありません。
TikTokの自社商品宣伝には商用コンテンツの開示を適用。音楽はCMLまたは用途を満たす自前ライセンス。TikTok内ライセンスを外部サイトや他SNSへ流用できると推測しない。[T3,T4]
AIによるリアルな画像・音声・動画はラベル必須。アニメ調でも今回の運用ではAI使用の説明を付ける方針。虚偽の証言・成績・本人なりすましを使わない。[T5]
有償で投資判断の助言をする業務は登録が必要になる場合があります。免責文だけでは回避できません。一般情報でも内容・対価・継続サポートで判断が変わるため、個別助言を追加する前に専門家/当局への確認を必須にします。[L1]
通信販売の事業者表示、価格、支払時期/方法、引渡し、返品/解約条件を整備。定期購入は次回以降の金額・更新・解約方法を最終確認画面でも明示。販売者の住所等を推測して埋めない。[L2]
