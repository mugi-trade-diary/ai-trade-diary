プライバシーポリシー

このサイトと、アプリ「Mugi Uploader」（以下「本アプリ」）での情報の扱いです。

1. 集める情報

このサイトは、訪問者の個人情報を集めません。会員登録・問い合わせフォーム・広告の追跡はありません。

本アプリは、運営者が自分のTikTok・YouTubeアカウントでログインしたときに、各サービスから受け取るアクセス用の鍵（トークン）と、アカウントの基本情報（表示名など）だけを使います。

2. 使い方

鍵は、運営者の動画を運営者のアカウントへアップロードするためだけに使います。他の目的には使いません。

3. 保管と共有

鍵は運営者だけが使える場所に保管します。第三者に渡したり、売ったりしません。

4. 削除

運営者は、各サービスの設定画面から本アプリの許可をいつでも取り消せます。取り消すと鍵は使えなくなり、保管している鍵も削除します。

Privacy Policy

This policy explains how this website and the app "Mugi Uploader" (the "App") handle information.

1. Information collected

This website does not collect personal information from visitors. It has no sign-up, contact form or ad tracking.

The App uses only the access tokens and basic account information (such as display name) that TikTok and YouTube return when the owner signs in with the owner's own accounts.

2. Use

Tokens are used only to upload the owner's videos to the owner's own accounts, for no other purpose.

3. Storage and sharing

Tokens are stored where only the owner can access them. They are never shared with or sold to third parties.

4. Deletion

The owner can revoke the App's access at any time from each service's settings. Stored tokens are then deleted.
